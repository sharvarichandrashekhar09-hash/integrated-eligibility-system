# Integrated Eligibility System (IES)

## Overview
Integrated Eligibility System (IES) is a Java-based web application developed using JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript.

The system helps manage government benefit programs through a centralized platform where applicants, caseworkers, and administrators can interact efficiently.

---

## Features

### Applicant
- User Registration
- User Login
- Apply for Benefit Plans
- Upload Documents
- Track Application Status
- Online Payment

### Caseworker
- Verify Documents
- Review Applications
- Approve / Reject Cases
- Manage Verification Workflow

### Admin
- Dashboard Analytics
- Manage Accounts
- Manage Benefits
- Government Allocation Tracking
- Distribution Management
- View Reports and Cases

---
